# GameLog

## アプリ概要

**「遊んだ記憶を、そのまま図鑑に。仲間と語り、次のゲームに出会える場所。」**

GameLogは、ゲームに関する活動を記録できるゲームレビューアプリです。
プレイ時間や感情を綺麗に記録・可視化し、多角的なリアルな口コミと掲示板でゲーマー同士が繋がるゲームライフログ＆コミュニティプラットフォームです。

## 要件定義

### 背景

自分自身が任天堂ゲームとスマホアプリを中心に遊んでいる中で、スマホゲーのサービス終了（サ終）によって思い出が消えてしまう切なさを体感したため作成しました。また、Switch等で撮り溜めた大量のスクショや熱中したプレイ時間を有効活用し、自分にとって一番テンションが上がる『ゲーム棚』を作り、同じような体験をしているゲーマー同士がリアルな本音で語り合える場所を提供したいから作成しました。

### ターゲット

- Nintendo Switch / スマホアプリ（ガチャゲー・サバゲー）を主軸に遊ぶゲーマー（ライト〜ミドル層）
- クリア実績やプレイ時間をひとまとめに管理・振り返りたい人
- 購入・ダウンロード前に「無課金での遊びやすさ」や「実際のプレイボリューム」を知りたい人

### 解決したい課題とその解決策

- 遊んだ記録が埋もれる：プレイ時間が分からない。→「プレイ時間ログ」として集約。
- 総合星評価（★4.0）の限界：星の数だけでは「無課金で遊べるか」「UIがサクサクか」「クリアまで何時間かかるか」が分からない。→「テーマ別構造化口コミ」で透明化。

### 利用シーン

- ゲームクリア後・イベント完走時: エンディングの余韻のまま、星評価・ネタバレありの長文感想・プレイ時間をまとめて記録。
- スマホゲーのガチャ・イベント後: ガチャ結果をトピック掲示板に投稿して仲間と盛り上がる。
- 次に遊ぶゲームを探す時: 「無課金で遊びやすい★4以上」や「クリアまで平均20時間以内」などの条件絞り込み検索でリアルな評価を確認。
- ゲーム体験を振り返る時: マイページの「ゲーム棚（カバー一覧）」や「人生の総プレイ時間」を見て所有感・達成感に浸る。

### 利用の流れ

1. ログイン: Google連携またはメールでサクッとログイン。
2. 検索・登録: 運営が厳選したタイトルの中から遊んだゲームを探し、「プレイ中」「クリア済み」「積みゲー」などのステータスで自分の本棚に追加。
3. 記録・レビュー: トータルのプレイ時間を入力し、多角パラメータ（スライダー）の評価、テキスト口コミ、思い出のスクショを投稿。
4. 交流・閲覧: ゲームごとの公式掲示板に入り、他の人のネタバレあり考察を読んだり、有益な攻略情報に「いいね」を押して交流する。

## 主な機能・画面

### 1. トップページ (`/`)

- ポータル表示
- キーワード/ハード別のクイック検索導線
- 最新コンテンツの閲覧

### 2. ゲーム一覧・検索 (`/games`)

- 多角条件による絞り込み・ソート検索

### 3. ゲーム詳細 (`/games/[id]`)

- ステータス登録
- ネタバレ感想の開閉表示
- タブ切り替え（レビュー / 掲示板 / マイ記録）
- トピック一覧閲覧
- 新規トピック投稿（モーダル）
- 自分のレビュー・トピックの編集・削除

### 4. レビュー・ログ投稿 (`/games/[id]/review`)

- レビュー投稿・編集（`?edit=[reviewId]`）
- プレイ時間の手動入力
- ネタバレフラグの設定

### 5. マイページ (ゲーム棚) (`/mypage`)

- ゲーム棚のビジュアル閲覧
- 総プレイ時間の自動集計表示
- 自身のプレイ記録のフィルタリング

### 6. 掲示板スレッド詳細 (`/games/[id]/board/[threadId]`)

- レス投稿・編集・削除
- 「いいね」カウント加算
- ネタバレ開閉

### 7. ログイン (`/login`)

- メール/パスワード認証
- Google OAuth（Supabase Auth）
- パスワードリセット申請

### 8. 新規ユーザー登録 (`/register`)

- 新規アカウント作成
- 確認メール送信
- 初期プロフィール設定

### 9. アカウント設定・ユーザー削除 (`/settings`)

- プロフィール・パスワード変更
- ユーザーアカウントの削除

### 10. 管理者ダッシュボード (`/admin`)

- ゲームタイトルの追加・編集・削除・公開/非公開
- 平均プレイ時間の登録
- 通報投稿のモデレーション/非表示化

## 環境変数

`.env.example` をコピーして `.env.local` を作成してください。

| 変数                            | 用途                                     |
| ------------------------------- | ---------------------------------------- |
| `DATABASE_URL`                  | Prisma / PostgreSQL 接続                 |
| `NEXT_PUBLIC_SUPABASE_URL`      | Supabase プロジェクト URL                |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Supabase 匿名キー                        |
| `GEMINI_API_KEY`                | Gemini テキスト生成                      |
| `ADMIN_EMAILS`                  | 管理者にするメール（任意・カンマ区切り） |
